# Nature Catalysis code-release notes

For code central to a manuscript's conclusions, the release should give editors, reviewers and readers enough material to inspect and reproduce the reported analysis: the exact source version, dependencies, input-data access/provenance, configuration, run instructions and generated outputs. A stable, versioned archival record and a clearly stated licence make the manuscript's Code availability statement verifiable.

This staging package provides the code boundary and a runnable demo, but it is not ready to be cited as the paper's complete code release until the items in `PUBLISHING_CHECKLIST.md` are complete. In particular, do not promise paper reproduction while the four study datasets, split provenance and exact historical configurations remain absent.

Check the current journal policy immediately before submission or revision, since editorial requirements can change: [Nature Catalysis editorial policies](https://www.nature.com/natcatal/editorial-policies).
