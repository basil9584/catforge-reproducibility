# Licence decision required

No `LICENSE` is included yet because the copyright holder and institution need to approve the code licence. Without a licence, a public GitHub repository is not an open-source release and other researchers have no clear permission to reuse the code.

Before publishing, decide whether an MIT, BSD-3-Clause, Apache-2.0, GPL-compatible or institution-specific licence matches the ownership and collaboration terms. Have the legal/institutional owner confirm the choice, add the exact approved text as `LICENSE`, then update the citation and manuscript code-availability statement.

Code and data may need different licences. Never assume that a permissive code licence authorizes redistribution of partner, published, proprietary or personally identifiable data.
